# Engineering Onboarding

## First week
New engineers get a laptop, VPN access and a buddy on day one. In the first week they set up the local environment with `orbit dev up`, ship a small change to production, and shadow the on-call primary for one day.

## First month
By the end of the first month new engineers should have joined the on-call rotation as secondary, read the incident severity and deploy process docs, and completed the security training.

## Access
Production database access is not granted during the first 30 days. After that it requires a request in the ACCESS queue and manager approval, and access expires after 7 days.
